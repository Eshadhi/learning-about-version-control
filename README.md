# learning-about-version-control
author: Eshadhi

Solving merge conflicts takes conscious effort, but I can do it!

What I like most about version control: I like being able to make changes while being able to easily get back to the previous version if anything goes wrong and to be able to track what changes I made each time. 

What I find most challenging: I find it challenging to remember to create branches and having to make sure I am working on the correct version.
